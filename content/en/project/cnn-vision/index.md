## CNN-Based Image Classification Project

A project designing and implementing a Convolutional Neural Network (CNN) from scratch using PyTorch for image classification and feature extraction.

### Key Implementations
- **CNN Architecture Design**: Composing Conv2d, BatchNorm, MaxPooling, and Dropout layers
- **Transfer Learning**: Fine-tuning pre-trained models such as ResNet and VGG
- **Data Augmentation**: Preventing overfitting with RandomFlip, RandomCrop, and ColorJitter
- **Model Evaluation**: Analysis using Confusion Matrix, Precision/Recall/F1-Score

### Tech Stack
- Python, PyTorch, torchvision
- NumPy, Matplotlib (Visualization)
- CUDA (GPU-accelerated training)
