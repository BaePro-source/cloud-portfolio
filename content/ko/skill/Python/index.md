## Python 프로그래밍

AI/ML 개발의 핵심 언어인 파이썬을 활용하여 데이터 분석, 딥러닝 모델 구현, AI 파이프라인 구축 등 다양한 분야에서 역량을 키우고 있습니다.

### 주요 활용 분야
- **딥러닝**: PyTorch, TensorFlow를 활용한 모델 구현
- **데이터 처리**: Pandas, NumPy로 대용량 데이터 전처리
- **AI 파이프라인**: LangChain, Hugging Face Transformers 활용
- **시각화**: Matplotlib, Seaborn으로 결과 분석

효율적이고 재현 가능한 AI 코드를 작성하는 것을 목표로 하고 있습니다.
